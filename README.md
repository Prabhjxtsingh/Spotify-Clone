🎧 Spotify Clone – React + Tailwind + Lucide Icons

A fully functional Spotify-inspired music player UI built using React, TailwindCSS, and Lucide Icons.
This project includes playlists, track lists, search functionality, liked songs, navigation history, dynamic gradient backgrounds, and a responsive audio player.

🚀 Features
✔️ Home Dashboard

Dynamic greeting based on time

Quick access to playlists and liked songs

"Made for You" personalized cards

Trending Punjabi & Hindi tracks preview

✔️ Fully Functional Music Player

Play / Pause / Previous / Next

Shuffle & Repeat modes (repeat-all / repeat-one)

Seek bar with live progress

Animated equalizer for currently playing track

Volume control

Auto-play next track

✔️ Search System

Live search filtering by song title or artist

Search suggestions when input is empty

Search clear button

Plays filtered results as a queue

✔️ Your Library

Playlists section

Create your own playlist with custom name

Dynamic playlist card previews

Liked songs section

✔️ Playlist Page

Dynamic header with cover + details

Track list with play-on-click

Auto-adjusted play queue

Track actions: Like / Options menu

✔️ Liked Songs Page

Displays all liked tracks

Play entire liked track queue

Empty state message

✔️ Sidebar Navigation

Home, Search, Library

Create playlist

View created playlists

Automatic history navigation

✔️ Responsive Design

Works across desktop and large screens

Adaptive layout

Hidden sidebar for smaller view sizes

▶️ Getting Started
🔧 Prerequisites

Make sure Node.js is installed:

node -v
npm -v

📥 Installation
git clone https://github.com/Prabhjxtsingh/Spotify-Clone
cd spotify-clone
npm install

▶️ Run Project
npm run dev


This starts the development server (Vite by default).

📦 Build for Production
npm run build
